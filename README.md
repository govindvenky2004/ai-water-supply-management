# AI Water Supply Management System

ML pipeline for water supply demand forecasting, anomaly 
detection and leakage prediction across 15 Indian cities.

## Built During
Infosys Systems Engineer Trainee Internship (Jan–May 2026)

## Tech Stack
- Python + PySpark (ML models)
- MySQL + MongoDB (databases)
- Power BI (dashboards)
- Gemini API (AI alerts)
- LightGBM, Random Forest, sklearn

## Project Coverage
- 15 Indian cities
- 1,809 wards
- ~568K records (2019–2024)
- 25 user stories
- 7 stakeholder roles

## Structure
- ml_stories/ → ML models (demand forecast, anomaly detection, burst risk)
- data_analysis_stories/ → Analysis scripts (climate, complaints, NRW audit)
- *.pbix → Power BI dashboards
- generate_dataset.py → Synthetic dataset generation
- preprocess.py → Data preprocessing pipeline
